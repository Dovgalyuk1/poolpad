# Pollpad — $POLL

Static one-page site, no build step. Settings at the top of index.html (CONTRACT, TWITTER, BUY_URL, WC_PROJECT_ID).

Post a poll, every option becomes a coin on Robinhood Chain; one vault per poll buys the winning option at close.
`assets/wc.js` is the WalletConnect provider bundle (loaded only when a phone wallet is used).
